## 🚀 MVP (Program Minimum — перед запуском)  

### Пользователи  
- [ ] Сохранение профиля на сервере (имя, email, телефон, страна, город, аватар)  
- [ ] Возможность редактировать данные регистрации  
- [ ] Авторизация с паролем (хэширование)  
- [ ] Привязка событий к пользователю (owner)  

### События  
- [ ] CRUD через сервер (создание, редактирование, удаление)  
- [ ] Приватные события → доступны только владельцу  
- [ ] Saved Events → синхронизация с сервером  

### Интерфейс / UX  
- [ ] Выровнять кнопки Submit/Cancel в формах  
- [ ] Завершить косметику Add Event (отступы, центрирование, чекбокс private)  
- [ ] Маска и валидация даты (более нативная)  
- [ ] Обновить дизайн вкладок в User Panel (Saved, My, Settings)  

### Интернационализация  
- [ ] Проверить переводы для всех кнопок/лейблов (чтобы не осталось дыр)  

### Техническое  
- [ ] Серверная база (например, Supabase/Postgres)  
- [ ] REST API (регистрация, логин, события)  
- [ ] Минимальные проверки данных и валидация
